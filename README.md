# Admin Dashboard

This is the Admin Dashboard project from The Odin Project. The goal of this project was to practice building layouts using CSS Grid. The website's layout and design was created using the provided [design file](https://raw.githubusercontent.com/TheOdinProject/curriculum/43cc6ab69fdfbef40d431a65677d2144668930ac/intermediate_html_css/grid/project_admin_dashboard/imgs/dashboard-project.png).
